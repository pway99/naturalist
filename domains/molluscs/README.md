# Molluscs

Will catalog the molluscs of Oak Vista — the garden's snails and slugs —
alongside the other organism domains.

A planned organism domain. It follows the shared organism-domain blueprint that
the insects domain established, and is currently skeletal — module scaffolding
only (`molluscs-api`, `molluscs-core`, `molluscs-repository-test` with their
poms), with no entities, queries, or seed catalog yet.
