# Microbes

Will catalog the beneficial soil microfauna of Oak Vista — beginning with the
entomopathogenic nematodes applied for biological pest control, whose species
identity, foraging strategy, and soil-temperature application window drive the
pest-management recommendations.

A planned organism domain. It follows the shared organism-domain blueprint that
the insects domain established, and is currently skeletal: `microbes-api` holds
an early `BeneficialNematode` sketch and a `ForagingStrategy` enum with a small
seed catalog, but the query, command, and repository layers are not built yet.
