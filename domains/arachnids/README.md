# Arachnids

Will catalog the arachnids of Oak Vista — spiders, predatory mites, harvestmen,
and pseudoscorpions — as beneficial garden predators, keyed by hunting strategy
(active pursuit, ambush, web builder) rather than a generic guild.

A planned organism domain. It follows the shared organism-domain blueprint that
the insects domain established, and is currently skeletal: `arachnids-api` holds
an early `ArachnidSpecies` sketch and a `HuntingStrategy` enum with a small seed
catalog, but the query, command, and repository layers the blueprint calls for
are not built yet.
