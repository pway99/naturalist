PR-2e — read-side queries and catalog contributions for family/genus

Plumbs the four new aggregates (InsectFamily, InsectGenus, PlantFamily,
PlantGenus) into the read-side namespace queries and the existing
catalog contributions, wraps them in test contexts, and updates the
unknown-token test queries that the new Boraginaceae common name
"Forget-me-not Family" caused to false-match.

api:
- InsectQuery: nested FamilyQuery and GenusQuery, accessor methods.
- PlantQuery: nested PlantFamilyEntityQuery and PlantGenusEntityQuery.
- InsectEntityCollections / PlantEntityCollections: FamilyCollection,
  GenusCollection (insects); PlantFamilyCollection, PlantGenusCollection
  (plants).
- Repository contracts gain getAllFamilyNames / getAllGenusNames.

core:
- New: FamilyQueryImpl, GenusQueryImpl, PlantFamilyEntityQueryImpl,
  PlantGenusEntityQueryImpl.
- InsectQueryImpl / PlantQueryImpl accept the new sub-queries.
- InsectsCatalogContribution / PlantCatalogContribution emit family +
  genus entries alongside species/plants. Tokens: slug, family/genus
  epithet, common-name labels.

test wiring:
- InsectsTestContext / PlantsTestContext wire the new repos + queries
  into the namespace InsectQueryImpl / PlantQueryImpl.

tests:
- InsectQueryImplTest: 4-arg constructor coverage with null tests for
  each sub-query, accessor coverage for families() and genera().
- InsectsCatalogContributionTest / PlantCatalogContributionTest: 3-arg
  constructor coverage, family/genus searchability, count assertion now
  sums species + family + genus.
- PlantCatalogContributionTest.unknownTokenReturnsEmptyResults and
  SearchControllerWebMvcTest.search_forUnknownTerm_rendersEmptyState:
  replaced placeholder query strings that contained tokens (e.g. "no",
  "not") which prefix-match the new "Forget-me-not Family" common name.

Out of scope:
- forFamilyName(...) / forGenusName(...) — defer to PR-3 (console).
- Linker arms in *-console for the new EntityName types — PR-3.
- Species genusName migration and InsectAggregateFactory rewiring — PR-2f.
